## 测试项

### 1) 中文输入
- [ ] 会话名称可输入中文并正常显示
- [ ] 任务标题可输入中文并正常显示
- [ ] 技能路径（含中文目录）可导入

### 2) 字体
- [ ] 默认字体回退正常（Microsoft YaHei UI / 宋体）
- [ ] 列表与表格中文不乱码

### 3) DPI
- [ ] 100% 下布局无重叠
- [ ] 125% 下控件不截断
- [ ] 150% 下表格可滚动且文字可读

### 4) 窗口缩放
- [ ] 最小窗口（900x620）可操作关键路径
- [ ] 最大化后表格自适应

### 5) 文件拖拽
- [ ] 可将技能文件拖放到路径输入区（若系统策略允许）
- [ ] 拖拽失败时可通过“浏览”按钮兜底

## 闭环验收步骤

1. 进入“技能管理”，导入一个本地技能文件。
2. 进入“任务列表”，执行 `echo 验收通过`。
3. 进入“工具调用日志”，确认有 `skill-manager/import` 与 `task-runner/exec`。
4. 进入“操作流水”，确认能看到 `import_skill`、`run_task`、`task_result`，并能查看输出/错误。
