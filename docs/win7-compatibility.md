# Windows 7 兼容性基线（Win7 SP1）

## 目标范围

- **目标操作系统**：Windows 7 Service Pack 1（Build 7601）
- **支持架构**：`x64`、`x86`（32 位）
- **不在范围**：Windows 7 RTM（无 SP1）、ARM 架构

## 最低依赖版本（版本钉死）

> 目标是避免自动升级到仅支持 Windows 10+ 的新版本。以下版本为当前项目的 **兼容性基线**，后续升级需在 Win7 SP1 实机回归通过后再调整。

| 依赖类别 | 组件 | 固定版本 | 说明 |
|---|---|---:|---|
| 运行时 | Python | **3.8.10** | 3.9+ 在 Win7 支持存在风险，统一锁定 3.8.10 |
| 包管理 | pip | **23.0.1** | 锁定已验证版本，避免工具链行为变化 |
| TLS/加密 | OpenSSL（随运行时） | **1.1.1 系列** | 避免仅面向 Win10 的新链路能力假设 |
| C/C++ 运行库 | Microsoft VC++ Redistributable | **14.29.30139** | 明确最低版本，避免缺失 DLL |

## 依赖版本钉死策略

1. 所有关键依赖必须使用精确版本（`==`）或 lockfile（不可使用范围版本如 `^`、`~`、`>=`）。
2. 发布构建必须包含依赖清单快照（带版本号）。
3. 任何关键依赖升级都需要：
   - Win7 SP1 x64 + x86 两套 smoke 通过；
   - `qa/win7-smoke-checklist.md` 核心项通过；
   - 记录变更原因与回滚方案。

## 验收口径

- 在 Win7 SP1 测试机上可启动。
- 核心 smoke 项（冷启动、网络、文件读写、子进程、日志）通过。
