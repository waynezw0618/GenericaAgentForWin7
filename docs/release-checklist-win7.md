# Win7 Release 检查项

> 发布前必须完成以下检查并留档。

## A. 杀软误报（False Positive）

- [ ] 使用至少 2 款主流杀软进行本地扫描。
- [ ] 使用 VirusTotal（或内部沙箱）检查样本。
- [ ] 对误报结果完成申诉并记录工单号。
- [ ] 发布说明中附“白名单路径建议”。

## B. 数字签名（Code Signing）

- [ ] EXE / DLL / Setup 全部签名。
- [ ] 验证时间戳有效且证书链完整。
- [ ] 执行 `Get-AuthenticodeSignature` 并截图留档。
- [ ] 确认 UAC 显示正确发布者名称。

## C. 离线安装（Offline）

- [ ] 离线安装包可在断网 Win7 SP1 完整安装。
- [ ] 无在线依赖阻塞首次启动。
- [ ] 示例任务可离线跑通（或有明确离线示例）。
- [ ] 离线文档与依赖清单完整。

## D. 升级策略（Upgrade Path）

- [ ] N-1 到 N 版本升级演练通过。
- [ ] 数据目录 (`data/`) 不被覆盖。
- [ ] 失败可回滚到上一版本。
- [ ] 升级后示例任务回归通过。

## E. 验收门槛

- [ ] 新机器按《install-win7.md》在 **15 分钟内**完成安装并跑通示例任务。
- [ ] 问题处置流程在《troubleshooting-win7.md》可闭环。
