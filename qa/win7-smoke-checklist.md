# Win7 Smoke Checklist

> 测试环境：Windows 7 SP1（x64 / x86）

## 执行前

- [ ] 运行 `scripts\win7_preflight.cmd` 并通过。
- [ ] 记录机器信息（CPU、内存、架构、补丁级别）。

## 核心项（验收必须通过）

### 1) 冷启动
- [ ] 首次启动时间在可接受范围内（建议 ≤ 30s）。
- [ ] 无崩溃、无阻塞。
- [ ] 主流程可进入可用状态。

### 2) 网络
- [ ] 可完成至少一次 HTTPS 请求。
- [ ] TLS 握手成功（建议 TLS 1.2）。
- [ ] 网络异常时能正确报错（可恢复）。

### 3) 文件读写
- [ ] 可在用户目录创建文件。
- [ ] 可读取已有配置/数据文件。
- [ ] 权限不足时有明确错误提示。

### 4) 子进程
- [ ] 可正常拉起子进程。
- [ ] 子进程退出码可被主进程捕获。
- [ ] 异常退出可记录并回收资源。

### 5) 日志
- [ ] 日志文件可创建。
- [ ] 日志包含启动、错误、退出关键事件。
- [ ] 日志编码可读（建议 UTF-8 或明确系统编码策略）。
